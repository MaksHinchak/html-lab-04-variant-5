# Лабораторна робота №4 — варіант 5

**Автор:** Максим Гінчак. **Тема:** проєктування вебдокументів, сторінка таблиць.

Навчальний сайт ByteMarket продовжує лабораторну №3. Основна сторінка роботи — `tables.html`: каталог із точною структурою об’єднань комірок варіанта 5 та таблиця доставки. Інформація про товари й ціни придумана.

## Запуск

Відкрити папку проєкту в PyCharm через **File → Open**, потім `tables.html` у браузері. Установлення пакетів не потрібне. Для локального сервера:

```bash
python3 -m http.server 8000
```

Відкрити <http://localhost:8000/tables.html>.

## Реалізація вимог

- Перша таблиця: 9 стовпців, 3 рядки заголовка, 4 групи по 2 рядки та 2 підсумкові рядки. `rowspan` і `colspan` відтворюють схему на сторінці 3 методички.
- Використано `table`, `caption`, `td`, `th`, `tr`, `thead`, `tbody`, `tfoot`, `col`, `colgroup`.
- Задані атрибути: `bgcolor`, `border`, `cellpadding`, `cellspacing`, `id`; `class`, `lang`; `axis`, `style`; `headers`, `rowspan`, `colspan`; `title`, `align`, `char`; `valign`; `span`, `charoff`.
- Друкарські помилки `aling` і `valing` у методичці виправлено на `align` і `valign`; відповідне оформлення також задано CSS.
- Застарілі атрибути залишені для демонстрації вимог лабораторної. Сучасне відображення забезпечує CSS; семантику таблиці доповнюють `scope` і `headers`. HTML5-валідатор може позначати застарілі атрибути.
- На вузькому екрані таблиці прокручуються горизонтально у власних контейнерах. Навігація веде на всі сторінки проєкту.
